# Git Commit Message Generator

Automatically generate Git commit messages following Conventional Commits specification.

## Usage

When you make code changes and need to commit:
- The AI will analyze your staged changes
- Generate a descriptive commit message
- Include the scope and description in Korean (if preferred)

## Example

```
feat(auth): 사용자 로그인 기능 추가

- JWT 토큰 발급
- 세션 관리 구현
```

## Best Practices

- Use semantic types (feat, fix, chore, etc.)
- Write clear, concise descriptions
- Include breaking changes when necessary
