# Security Policy

## Supported versions

Security fixes are applied to the latest maintained release line. If you are running an older build, upgrade to the latest release before filing a report.

## Reporting a vulnerability

Do not open public GitHub issues for suspected vulnerabilities.

Use one of these private channels:

- GitHub private reporting: https://github.com/aroido/vibesmith/security/advisories/new
- Email: admin@aroido.com

Include:

1. A clear description of the issue
2. Reproduction steps or a proof of concept
3. Impact and affected components
4. The version, platform, and environment used

## Response expectations

- Initial acknowledgement: within 48 hours
- Follow-up status update: within 7 days
- Fix timeline: based on severity and reproducibility

## Contributor guidance

- Never commit secrets, credentials, or private tokens
- Prefer environment variables for sensitive configuration
- Run the relevant tests and validation checks before opening a pull request

## Disclosure

VibeSmith follows responsible disclosure. Fixes are released as soon as practical, and reporters are credited unless they request otherwise.
